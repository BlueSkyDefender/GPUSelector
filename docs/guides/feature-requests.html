Feature Requests

Have an idea that would make GPU Selector better? We'd love to hear it.

How to Request a Feature

The best way to request a feature is to open an issue on GitHub:

  1. Go to GitHub Issues → New Issue
  2. Use a clear title like "Feature Request: [your idea]"
  3. Describe what you'd like to see, why it would be useful, and any examples
  4. Submit the issue
Search first: Before opening a new issue, search existing issues to see if someone already requested the same thing. If so, add a thumbs-up reaction to show your support.

What Makes a Good Request

  • Be specific — "Add support for X emulator" is better than "add more emulators"
  • Explain the use case — Why do you need it? What problem does it solve?
  • Include examples — Screenshots, links, or comparisons help clarify your idea
  • Keep it focused — One feature per issue makes it easier to track and implement

Report a Bug

Found something broken? Report it the same way:

  1. Go to GitHub Issues → New Issue
  2. Use a title like "Bug: [what's broken]"
  3. Include: what you expected, what happened instead, your Windows version, and GPU model
  4. Screenshots and steps to reproduce are extremely helpful

Report a Broken Codex Link

If you find a dead link in the Modding Codex, report it on GitHub Issues. Include the project name and the broken URL so it can be updated or removed.
