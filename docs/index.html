GPU Selector

A multi-GPU game launcher for Windows. Choose which GPU to use for each game, manage emulators, and install modding tools. All from one app.

Download v1.2.5 Getting Started

🎮 Multi-GPU Forcing

Launch any game on a specific GPU, whether Intel, NVIDIA, or AMD. Three streamlined force methods cover everything from DX9 to Vulkan.

📚 Game Library

Automatically detects games from Steam, Epic, GOG, EA App, Ubisoft Connect, Xbox, Battle.net, Amazon Games, and itch.io. Add custom games manually.

🎬 Emulator Support

Manage emulators with ROM folder scanning, per-emulator configuration, launch arguments, and direct emulator downloads.

🎨 ReShade Integration

Install and manage ReShade with version selection, build types, Inject Mode with custom overlay key and gamepad navigation, add-on management, and shader packs including Depth3D and CShade.

⚡ Translation Layers

DXVK, VKD3D-Proton, dgVoodoo2, WineD3D, and Zink. Translate between graphics APIs for performance and compatibility.

🛠 Modding Codex

A curated database of community game projects including decomps, ports, remakes, fixes, VR mods, and more. Search, filter, and star your favorites.
